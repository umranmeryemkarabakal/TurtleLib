## 🇬🇧 Overview

Four short programs that introduce Python's turtle graphics: basic drawing, a shrinking square, a colourful spiral helix and keyboard-controlled movement.

**Quick start:** `python 03-spiralHeliks.py`

## 🇹🇷 Proje hakkında

Python `turtle` modülüyle çizim temellerini anlatan dört kısa program.

## 📚 İçerik

- `01-drawing.py`: ekran, kalem ve temel hareketler
- `02-square.py`: küçülen kare
- `03-spiralHeliks.py`: renkli spiral sarmal
- `04-inheritence.py`: klavyeyle kaplumbağa kontrolü

## ⚙️ Kurulum ve çalıştırma

Ek bağımlılık yoktur.

```bash
python 01-drawing.py
```
